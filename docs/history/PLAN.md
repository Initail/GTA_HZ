## 执行顺序

1. 恢复独立、完整上游检出及 LFS，校验实际内容；原版运行、单测、构建和实机建立基线。
2. 建立 JSON 城市配置、TypeScript/Python 共用投影、资产目录、存档命名空间、任务地点和街景参数。默认仍为深圳基线，杭州资产和地点通过门槛后切换，禁止把深圳资产改名冒充杭州。
3. 下载固定日期 Geofabrik 浙江 PBF，校验长度/MD5/SHA256/OSM 数据时间；裁切连续范围。以 OSM 节点和层级生成导航，保留桥/坡道，拒绝二维相交自动连边。
4. 生成杭州道路、楼体、水体、绿地、地形和所有布点；在独立候选目录检查连通性、排除楼体、入口与道路高度。
5. 菜鸟、阿里 A/B/C、杭州之门、武林、西湖、灵隐、钱江新城与奥体逐对象补证、建模、立面、夜景、候选验收。身份、足印或高度未确认保持 blocker。
6. 串行集成：基础楼体和近景立面排除、碰撞、水材质、地图到达点、咖啡馆、街景、职业和顺路故事。奖励、价格、分支、品质、升级、反作弊、载具操控不变。
7. 全套自动回归与真实浏览器操作；逐对象俯视/街面/远景截图和昼夜对照；冷启动、内存、帧时；正式构建与刷新恢复。

## 事实与限制

- 当前目录最初仅有无提交 `.git`；源码从干净只读副本复制，副本采用 sparse-checkout 且 blob 过滤，城市 JSON、GLB 和 LFS 本体缺失。
- 初次不完整检出测试：244 项，215 pass、29 fail、0 skipped；多个文件级测试因缺失输入未注册全部用例。2026-10-13 公共运行资产已恢复，完整原版 288 项为 287 pass、1 UE5 实验资源 fail；正式构建通过。实机仍受浏览器站点设置阻止，不能把规则/资产检查写作实机通过。
- `npm ci` 使用原锁文件，未升级依赖；Node 24.13.0、npm 11.6.2、git-lfs 3.6.1；Blender 已安装。
- `npm run assets -- --plan` 已执行，缺少原始地图、DEM/车辆/贴图源输入；未执行深圳全量重建。
- 空闲候选端口 5199（基线）与 5200（杭州候选）。启动前再检查；不关闭其他服务。
- 上游 `node_city_roads.py` 的二维 `unary_union` 会引入高架伪路口。杭州需要 OSM 共享节点及层级，几何相交不能证明转弯可达。
- 职业代码实际将 `park` 绑定 `workshop.arrival`，将 `workshop` 绑定 `office.arrival`。迁移必须保留任务语义并用明确五点配置替代该隐式复用。
- 西兴大桥当前改建封闭，不能把旧 OSM 可通状态当作当日路况；城市快照呈现年代与施工限制应单独记录。
