# 体验反馈与后续实施方向

本轮来自用户实际体验。用户观察到景区画面像普通高楼街区、白堤桥面出现断口、封闭园区车辆通行过于自由、地标指示牌与大门标识不足，以及初始画面长期呈现夜色。上述体验问题作为后续验收依据。

## 场景与地标

优先修复白堤、锦带桥、断桥的连续可步行路线，并逐段核对水面、桥面、地形、护栏与入口。灵隐以寺院、五殿、台阶、山林和入口为重点。西湖以湖水、堤岸、桃柳、桥洞和休闲步行为重点。普通建筑需核实真实用途与高度，景区范围内被替换的基础建筑、立面必须同步排重。

验收采用同位置白天俯视、街面、远景与步行录屏，并核对来源照片。灵隐已有五殿独立模型，西湖已有基础水面，当前工作重点是模型品质与整城接入在实际体验中的表现。

## 通行与交通

将机动车、步行、自行车、公交与管理车辆通行语义纳入城市资料。封闭园区、景区步行路、门禁和公共道路分别按来源设置通行权限。导航、NPC车流、自动驾驶、目的地停车点须遵守同一权限。开放步行入口应与可停车的公共道路连接。

公交系统作为新增玩法范围推进，先建立可追溯线路、站点、班次和乘降闭环，并与既有红绿灯、车流联动。红绿灯已有模型、布点与停车接口，需要在体验版逐路口核验。封闭园区的门禁规则、开放时段与公交运营信息在实现时核对来源。

## 指示与标识

关键地标提供名称、入口、停车或步行到达提示。寺院和园区补大门、牌匾及导向系统。标识位置需与实际入口对应。未取得发布许可的照片继续仅作参考。

## 时段与天气

杭州体验默认从白天开场。界面直接选择白天、日落、夜晚，以及晴朗、阴天、雨、雪。时段和天气独立组合，原雨天积水、反射和音效继续接入。第一轮降雪以局部飘雪与阴天天空表达，地面积雪与季节植被列为后续实现，评估资源预算与场景避让。

## 本轮已核实

- 当前体验白堤模型铺装与角色物理采样高度有多米差异。复现脚本在真实压缩地标GLB上发射射线，并比较实际步行采样与碰撞。原始失败报告保留。
- 原体验已有日落、夜晚、白天与雨天快捷键。新一轮把时段和天气加入可见选择控件，杭州默认白天。
- 灵隐已有独立殿堂模型。景区表现仍应以用户实机观感、接地与周边遮挡验收。

## 接下来执行

1. 白堤与桥面故障复现、逐段接地和步行支撑修复。
2. 灵隐和西湖的实景表现、入口与普通楼体排重。
3. 访问权限与导航修正，补入口、大门和地标指示。
4. 公交线路与乘降功能，再与信号灯和车流联合验证。
5. 逐步完善天气、季节视觉，并在白天和夜间回归全部玩法。
