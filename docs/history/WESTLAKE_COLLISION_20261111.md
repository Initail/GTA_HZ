# 西湖碰撞候选 v12 · 2026-11-11

用户复现场景：断桥、白堤附近开车靠近水会停，车辆之间碰撞没有体感。本轮交付独立候选 `artifacts/cities/hangzhou/westlake-collision-v1`，没有覆盖根目录玩法源码或冻结 v11，也没有自动打开完整游戏。

## 已实施

- 车辆之间从 2.7g 车心圆距改为带方向与高度的车身接触。轿车外形采用原行人撞击模块的 1.03g 半宽、2.5g 半长、1.45g 高度；原 .15 回弹系数用于接触冲量。接触时保留已完成的安全位移，产生减速、NPC 短暂受撞位移、衰减镜头震动和原音效总线上的撞击声。连续顶住不每帧播放，倒车退出、并排有缝、沿接触面滑动和不同桥面高度分别测试。
- NPC 的受撞位移检查静态阻挡，不能因推挤穿到水域或结构中；衰减后回到原车道。NPC 识别玩家所在车辆/步行身体，步行碰撞也纳入同层 NPC 车辆，修复桥上停车挡住桥下人物的二维误挡。既有巡航速度、红灯、单向死端、方向规则不改。
- 水域与机动车限行分别提示。真实西入口公共路 `way/4398107` 能正常前进，在白堤 `way/4326974` 的 `motorcar=no` 区域停车。
- 原城市道路表只保留了白堤第一段机动车源记录。旧数据在698个源中心点上给出455个无阻挡、93个限行、150个水域；因此不能用水域阻挡代替后续步行道限行。新增6条来源绑定的 `accessCorridors`，附着于实际步行支撑面；577个后续路段采样点禁止机动车，698个步行中心点保持通行，公共路口仍开放，不影响桥下其他层。保留原始 bicycle/motor_vehicle 等标签，未来骑行必须尊重其中禁骑路段。
- 通行走廊宽度沿用既有模型估计宽度，不冒充实测。来源为固定 Geofabrik OSM 快照、已有白堤/断桥证据包及路线输入，记录在 `site-access-provenance.json`。仅更新场地表面附加规则及其哈希链；地形、湖水、铺装三角面、护栏、地标模型、道路图均未修改。

## 本轮证据与限制

29项针对性测试通过；原有步行、坦克、行人撞击、路权、单向导航和场地支撑的127项回归子集通过。旧自动驾驶整城测试仍因256MiB上限终止，不能标为通过。新增纯碰撞/场地模块严格类型检查通过；完整TypeScript与正式Vite构建未通过当前限制。外部依赖源码打包及361个实际ESM导出检查通过。

本轮所有离线子任务保持10秒/256MiB限制。首次整体世界导入、整体自动驾驶回归等资源超限报告保留；没有提高阈值或关闭他人应用。CPU世界测试直接提取实际方法来隔离渲染导入；不构造GPU场景。源中心点检查不是完整足印行走或实机驾驶；旧v8实机往返不能当作本版本证明。

本轮没有浏览器画面、声音、完整玩法或性能验收；用户此前“没有再闪崩”也不等于watchdog问题解决。水域仍保留车辆阻挡，尚未新增落水/漂浮/救援机制。自行车、游船、钓鱼、更多NPC互动及西湖实景建模继续在后续范围。

详细机器记录在 `validation-summary.json`，固定包在 `delivery-check-lan-v1.json`；原失败与最终通过报告均在 `docs/hangzhou/audit/stability-20261111/`。`source-changes.patch` 是相对冻结v11的6个源码文件差异，不应盲贴到其他基线。

## 手动试玩

- 新入口：http://30.113.0.92:5204/；本机也可用 http://127.0.0.1:5204/。同学须在可访问该IP的局域网。
- 启动时间：2026-11-11 18:34:27 +08:00；到19:34:27自动结束。旧v11未重启、未延长。
- 首页没有脚本或画布；手动确认后进入，默认低画质。已核验主机经LAN IP访问、进入门禁、最终应用包、三份覆盖JSON及分块清单的实际响应和哈希。未证明另一台设备可连接，也没有通过HTTP请求启动游戏。
- 建议先在白堤西侧公共道路低速接触NPC、侧擦、倒车离开，再到步行入口下车。重点反馈碰撞是否过硬、镜头震动幅度、车辆是否穿插，以及看到“水域/限行”提示的位置。

服务停止后，在项目根目录手动执行（同一端口无其他服务且内存压力正常时）：

```sh
python3 -u scripts/serve_hangzhou_westlake_demo.py --port 5204 --host 0.0.0.0 --advertise 30.113.0.92
```

IP可能随网络变化；脚本不会自动启动浏览器。服务器最多4个并发连接、单连接30秒超时，1小时退出，沿用原手动进入与路径限制。脚本只服务独立候选和冻结基础资产。
