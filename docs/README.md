| 目的 | 入口 |

| 操作游戏、理解模式与存档 | [CONTROLS](CONTROLS.md) |
| 了解本轮交付与未完成项 | [STATUS](STATUS.md)、[ROADMAP](ROADMAP.md)、[CHANGELOG](../CHANGELOG.md) |

| 建模、重建、候选验收 | [REBUILDING](REBUILDING.md)、[SCRIPT_INDEX](SCRIPT_INDEX.md)、[RESEARCH](RESEARCH.md) |
