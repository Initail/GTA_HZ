# 操作与玩法

使用桌面键盘与鼠标，先点击欢迎页「进入杭州」。游戏内提示会随模式变化；输入框中打字不触发驾驶快捷键。

| 按键/入口 | 用途 |
| --- | --- |
| W/A/S/D 或方向键 | 行驶/移动；手动驾驶输入接管自动驾驶 |
| Space | 汽车手刹；坦克/飞机发射；钓鱼模式按当前提示控线 |
| F | 上下车，步行与车辆切换 |
| Shift | 步行跑步（按模式提示） |
| C | 汽车镜头轮换；步行第一/第三人称；单车/游船镜头切换 |
| R | 恢复至道路；会影响真实驾驶验收，报告需标记 |
| H | 喇叭 |
| M / Tab | 打开/关闭地图 |
| 地图 UI | 搜索、路线、自动驾驶、观景、快速移动、收藏 |
| J / E | 任务日志 / 当前地点互动 |
| K | 职业入口 |
| N | 自行车模式，按地点/路权限制取车、下车和停放 |
| Q / Space | 在合适的湖畔位置进入钓鱼/抛竿与控线，遵循屏幕提示 |
| T | 坦克模式；Q/E 调炮塔，PageUp/PageDown 调俯仰，X 手刹 |
| B | 飞机模式，屏幕显示飞行操作 |
| G | 无人机航拍 |
| V | 车辆观景/退出观景 |
| L / Y | 时间/天气切换；画质面板也提供入口 |
| P / Esc | 帧率显示 / 暂停或退出当前界面 |

步行进入咖啡馆后用 E 对话。园区或景区的限行不等于故障；停车后按步行入口进入。水域目前仍阻挡汽车，落水漂浮/救援不是已实现系统。白堤/断桥路权依据固定源数据和已编制步行面，仍需逐入口实机验收。

职业、六份合约、升级、关系与故事奖励沿用上游规则；杭州地名及任务到达点经过适配。存档键采用独立 `gta-hz` 命名空间，不读取深圳收藏和旧任务位置。使用浏览器隐私模式/清理站点数据会影响持久化；不同端口的存档互不共享。

公开版使用原创骑手与咖啡人物，外观与旧私有试玩不同，操作和交互接口保留。公交源线/车辆/站台目前为候选模块，不提供已完成全城公交系统的承诺。新增休闲经济和原职业结算保持分离，重复领取规则由测试保护。

`/combat-lab.html` 是独立靶场：鼠标瞄准/射击，R 换弹，Esc 暂停。它不接入主城职业或武器经济。仓库的 `trailer.html` / `src/trailer-capture.ts` 保留历史录制源码，其深圳镜头和整城初始化尚待迁移，不随默认 `dist` 发布。
