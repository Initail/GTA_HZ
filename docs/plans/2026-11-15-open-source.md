# 开源工程交付计划

范围：将本地 RC2 阶段成果导出为独立 GTA_HZ 工程，发布到 Initail/GTA_HZ。旧工作区与 upstream 保留。此交付不等于所有地标与玩法实机终验完成。

1. 审计 RC2 源码、依赖、测试夹具、资源授权；有明确再分发限制的资源使用原创替代，保留功能契约。
2. 建立独立新仓库，锁定依赖；统一安装、类型检查、测试、构建、资源获取与启动入口，消除旧候选路径依赖。
3. 保留可执行源码和模型脚本；运行资源按 SHA256 清单分发，地理数据保留 ODbL 来源。
4. 编写新贡献者与 Agent 的按需文档索引、架构、坐标、资产、验证、协作流程和真实待办。
5. 在新目录执行检查和构建；在当前资产上做有限浏览器烟测，记录范围与未通过项。
6. 检查公开文件的许可、秘密、本机路径及体积，创建全新公开 GitHub 仓库并推送；核对远程提交和资源下载流程。

完成标准：新协作者能从仓库文档定位真实入口、安装固定依赖、取得公开资源、运行和验证；仓库链接可访问；已知阻塞不包装成通过。

设计选择：源码和可重建脚本入 Git，体积大的可公开资源用独立 Release 包和校验清单。保留 RC2 两步打包与兼容画质策略；不重写玩法。
