# 当前交付状态

更新：2026-11-16。版本：`0.16.0-rc.3`。这是从 RC2 导出的独立开源工程，不是全部杭州地标与原玩法的最终交付。

## 本轮变化

- 固定依赖、独立安装与构建入口，测试不再读取旧候选目录。
- 手动进入主城，保留 RC2 低画质、分块加载、步行人物懒加载和 context lost 恢复策略。
- 公开资源包排除受限人物和授权不明的 Tripo 模型，使用带骨骼/动画的原创骑手、两款咖啡员工与可转动炮塔的坦克。
- 源码与大资源分发分离，包/文件 SHA256 验证，OSM 衍生数据库可随资源包获得。
- 增加开发、架构、坐标、重建、协作、验证和许可入口；保留上游 MIT 与数据/资源署名。

## 证据边界

本轮命令及结果在 [验证记录](validation/open-source-rc3.md)。独立迁移测试阶段曾得 409 项通过；集成后的实际结果以该记录为准。原创模型已通过静态契约和 Babylon NullEngine 导入，但不能据此认定人物外观或主城全玩法通过。

RC2 历史实机：低画质出画、体育场路驾驶达到 41 km/h、刹停、累计约 0.2 km、地图开关和下车。该结果来自旧阶段记录，不替代 RC3 的当前验证。更早 Mac 曾有系统 watchdog/图形命令失败，根因未确定，不能声称优化已解决整机重启。
