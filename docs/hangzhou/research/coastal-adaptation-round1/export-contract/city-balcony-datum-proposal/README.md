## 楼坪选择与连接形态

均衡两岸端中心：`upper=(5.767362787+5.348441219)/2=5.557902003`，`base=upper-3.6=1.957902003`。这是使两个岸端中心的最大绝对高差最小的明确游戏改编选择，下层高于当前水面1.057902003g。

西中心连接上升0.209460784g/32.204303g，约0.6504%；东下降0.209460784g/30.123200g，约0.6953%。这些几何坡比说明无需为高差凭空增加整座楼梯；它们**不等于法规无障碍认证或真实坡道证据**。实际端边横向高度也不同，不能用单一中心高度封整条宽边。

`datum-candidates.json` 另保留上层取较高岸端5.767362787（base2.167362787）、全端边极值均衡5.577257102（base1.977257102），以及当前中性base0的结果。较高岸端方案东中心下降0.418921568g，约1.3907%；不会自动消除下层碰撞。不要为了消除碰撞不断抬高整栋模型。

`upper-finger-profile-proposal.json` 是只在已有足印内的连续高度场诊断稿：主内边上层固定，岸端按当前地面拟合。有限差分最大梯度西约2.203%、东0.934%。该稿采用中心轴权重，尚未对每个斜向端边顶点建立精确边界插值，因此**不是可直接生产的最终坡面**。生产应把源内边约束为共同上层，源外边所有≤1g采样点约束为对应 ground，做有界三角化/高度插值后再次验证。

西诊断上层仍低于当前 terrain 最多约0.279392g；东差值约[-0.035744,+0.236187]g。因此只抬模型会埋入局部地形。需在这两个有源 finger 及确有必要的最小接边带内，做明确 estimated 的 terrain 接缝或高架地板层处理；不能把整片下层公共空间填满。过渡支撑/栏杆/坡面须一致，不能只改视觉顶面。

## 保留现有模块接口的最小实现提案

1. `lm.y` 始终表示下层绝对楼坪，上层为 `lm.y+3.6g`，不能用模型地基minY=-1.8g设地坪，也不能把anchor地面再加到上层。
2. 保留 `deck_height_metres(..., level)` / `deck_height_game(..., level)` 的 upper/lower 语义及调用接口。在内部增添明确的 source-finger 上层高度查询；下层仍采用独立下层楼坪。边界到达点需要显式容差/边界归属，不能依赖 `_inside` 的边界偶然结果。
3. `build` 只对这两条来源足印内的上层三角面应用高度场；底板保持同一局部0.39g厚度，侧封口、栏杆立柱与横梁、接近段代表性桥墩顶部同步。主楼、下层地板和玻璃体不得用整栋统一变形来凑坡。
4. `ground_footprints` 保持精确窄墙/柱形状及 `minYGame/maxYGame`，修正被变化的接近段柱顶；不能转为覆盖主阳台的整片障碍。玻璃房空腔和上下层公共空间继续分开。
5. 运行时上/下层脚下高度选择必须按当前所处层和人物高度；单一 terrain ground(x,z) 不能代表同一平面位置的双层楼板。源轮廓/路径交叠不产生上下层或隧道入口。
6. 台阶、楼梯、电梯的实际位置仍 unknown。此轮可以制作明确标注 estimated 的平缓源足印上层过渡；不能声称已还原真实楼梯或开放下层入口。

`source-floor-shore-intervals.json` 给出600g岸源线内的精确局部所有权范围：与上下公共地板同一投影相交四段 `[198.467881,211.179086]`、`[259.663686,273.160500]`、`[290.907797,322.627531]`、`[377.003128,393.407328]`，合计74.331953g；中间另与三块有源玻璃体投影相交48.484600/17.747297/54.375597g。站距从本候选岸源线起点量，不是任意道路站距。

主集成应在锁定 datum 后，只对这些精确结构占据/公共楼板区间定义最终的岸体接触：例如公共楼板下保留低于下层板底的有界岸体，公共空间高度内不保留穿墙/穿地板裙面；与墙/柱的接触按实际边界贴合。玻璃体内部不能等同公共地板。局部岸体、可见 terrain 和物理采样/碰撞须采取同一所有权规则，重新封闭实体后复算。**这些区间不是预批准的隐藏遮罩，不能仅删可见岸面而保留阻挡地形，也不能删整个600g岸线。**

完整相交面编号、坐标见 `datum-vs-four-shores-3d.json`。直到这一层完成，建议base仍是 candidate；该对象/该岸段保持 blocker。
