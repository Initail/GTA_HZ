# 杭州原创林冠原型与植被证据

本轮交付八种原创程序化树型 × 三级 LOD：香樟、垂柳、桂花、银杏、二球悬铃木、碧桃、枫香、马尾松。纯 B 模块为 `scripts/landmarks/hangzhou_tree_palette.py`，24个独立导出参数在 `prototype-specs/`。没有修改共享 planting、运行时或总GLB，没有在本任务运行 Blender/浏览器，也没有生成实际树点。

这里的“原生对象”是项目原创几何资产；并不把所有树种称为中国原生植物。悬铃木是引种栽培的常用行道树，来源和名称与本土樟、枫香等分开记录。碧桃为观赏品种族，具体栽培品种和各株身份 unknown。原型不复原某一棵古树，不复制照片纹理。

## 尺寸、季相与树型

全部原型尺寸为 **estimated**：根据来源的大/小乔木类别与冠型，选择可辨识、可维护的成年树艺术原型，并给出误差。没有现场测高、胸径或冠幅测绘；没有树木普查。高度和林冠半径不是所引网页直接 reported 的“杭州平均值”。

| 树型 | 实米高 ±估计误差 | 实米冠半径 ±估计误差 | 游戏单位高 / 冠半径 | 形体区分 |
|---|---:|---:|---:|---|
| 香樟 | 18±5 | 6.8±2.0 | 10.8 / 4.08 | 宽圆密冠、分叉主枝 |
| 垂柳 | 11±3 | 5.0±1.5 | 6.6 / 3.00 | 拱展主枝、细下垂枝、长垂叶簇 |
| 桂花 | 5.5±1.5 | 2.6±0.8 | 3.3 / 1.56 | 常绿矮密圆冠、静态秋花建议 |
| 银杏 | 17±5 | 4.0±1.5 | 10.2 / 2.40 | 直立卵圆冠、升高分枝、少量近景原创扇形叶 |
| 二球悬铃木 | 20±6 | 7.0±2.5 | 12.0 / 4.20 | 宽分叉冠、浅色分片树皮；不是一种普通“梧桐” |
| 碧桃 | 5.0±1.5 | 2.8±0.9 | 3.0 / 1.68 | 低开张分叉、静态春花建议 |
| 枫香 | 20±6 | 5.3±1.8 | 12.0 / 3.18 | 高直不规则卵形冠、静态秋色建议 |
| 马尾松 | 22±7 | 5.6±2.0 | 13.2 / 3.36 | 成熟疏层伞状针叶冠、有层间留空；不做单一绿锥 |

`summer/spring/autumn/winter` 是可选的静态资产参数，不新增季节玩法或定时变材质。默认全部导出参数为summer。常绿树冬季保留林冠，落叶树的winter候选去掉叶冠；银杏秋色和碧桃春花只在该静态参数下表现。实际年度物候、品种、养护、落叶过程、精细叶/花/树皮尚未验收。

城市组合在 `palette-spec.json.scenes`：西湖桃柳、城区樟/悬铃木/银杏/枫香、公园桂花低层与桃、山地樟/枫香/马尾松混冠。它们是 source-informed 配色/树型建议，不是生成比例；黄山栾树等当地常见树尚未制作，本包不代表杭州全部植物。

## 单位与纯 B 接口

接口为 `build(b,lm,spec,scale=.6)`；每个spec只建一物种/一LOD，根在局部0。输入高度/冠径用实米，水平与垂直在此函数各乘一次0.60。`lm.x/z/y` 是游戏单位，仅平移；通用导出器的spec anchor使用canonical杭州原点以产生局部原型，不是杭州某棵树的实测位置。

导出原型的 `heightGame/crownRadiusGame` 已是游戏单位，运行时只乘 `variationScale` 和 yaw/terrain平移。主集成不能再次给GLB乘0.60，也不能把实米冠径填进runtime species.crown后参与游戏单位避让。既有 Blender东/北/上→GLB→Babylon方向处理继续由父构建器/loader负责。

默认 materialMap使用现有 `bark/leaf/leaflight/pavement`，可直接运行B构建，但花/秋色的默认材质颜色只是近似。模块 `material_definitions()` 返回七个共享哑光PBR槽位；父构建器可注册一次，再将对应name映射进spec.materialMap。没有在模块导入时创建材质/灯光/场景，也没有源照片或透明叶卡。CPU配色图模拟的是这套原创颜色，未证明GPU材质通过。
