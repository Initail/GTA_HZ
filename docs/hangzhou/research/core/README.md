# 杭州核心地标公开证据调查

调查日期：2026-10-12（Asia/Shanghai）。范围仅为核心地标公开证据，不包含模型构建、坐标测量、照片贴图授权或实机验收。每个对象的证据在 `<id>.evidence.json`；统一来源索引为 `sources.json`，本轮研究文件的 SHA256 在 `research-hashes.json`。

沿用上游 `skills/landmark-reconstruction/SKILL.md` 与 `docs/landmarks/agent-workflow.md` 的证据分类和阶段契约。本目录没有替任务生成器填写 `evidence-ready`：所有 WGS84 中心、足印与真实朝向仍等待主集成取得的 OSM 快照核对，`location.center` 保持 null。来源中公开的建筑高度是 reported，不是本轮 measured。尚未作尺寸估算，未知项不会以 0 或假精度替代。

## 阻塞项与下一步

1. 主集成用固定哈希的 WGS84 OSM 确认每对象 center、源 feature ID、足印、朝向和入口；不同商业地图的定位不直接混入。
2. 用有来源的 DEM 冻结灵隐五殿台阶与夕照山的基面；白堤/苏堤 0.4 m 是历史 reported 相对湖面，不能当当前 DEM 绝对高程。
3. 每对象收集至少两个方向的现状照片并逐图标定。已定位的官方图不是已完成视觉审计，未获取图不记录虚构 SHA256。
4. 对精确高度/连桥标高/阳台尺寸冲突，取得设计剖面或当前官方技术资料再冻结；先制作可辨识形体候选不会解除这些 blocker。
5. 地标水面归基础水体，桥、堤、平台加入独立地面/碰撞；道路目的地放到真实可达入口或路边，无车行入口的景点用步行到达点。
6. 本目录的研究哈希只证明本轮研究记录的字节，不是远端网页或照片哈希，也不证明模型、碰撞、性能或八项 verified 通过。
