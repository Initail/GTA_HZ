# 菜鸟总部周边道路通行证据（round 1）

调查截止日：2026-10-16。当前交付是有限道路身份、公告及原始节点对应的证据包，未修改原始 PBF、共享道路、世界或运行时；没有实机驾驶验收。

## 可供主集成采用的结论

**2023 年公安官方完整公告支持两段市政道路已开通：云联路“凤新路—文二西路”、菜鸟北路“云联路—数云路”，日期为 2023-05-12。** 该公告将其分别列为城市主干路、城市支路，均为双向四车道，并部署电子警察、要求行人和车辆遵照信号及标志标线。公告没有将这两段限定为园区职工、施工车辆或持证车辆专用。

由此可作出的**有来源推断**是：两段属于一般公共城市道路，可为游戏普通车辆生成有来源的分段通行覆盖。原始 `access=no` 保留，覆盖写入派生适配层并保留公告、日期、原始 way/version/node 范围。该推断不能扩大成所有车型、所有时段均无限制，更不能当作总部内部道路开放证明。页面元数据“公开范围：面向社会”仅表示信息公开范围，单独不证明道路开放。

完整官方来源：[关于菜鸟北路、云联路道路通车的通告](https://www.yuhang.gov.cn/art/2023/5/11/art_1229175530_4164198.html)，杭州市公安局余杭区分局交通警察大队，2023-05-11 15:23，索引号 `002510856/2023-153639`。本轮 HTTPS 抓取失败，HTTP 公开入口成功，全文原始 HTML 见 [gov-http-test.html](references/gov-http-test.html)，响应及哈希见 [followup-fetches.json](followup-fetches.json)。

## 2026 年北延与实际临时限制

余杭发布官方微博的搜索索引列出“云联路（文二西路—文一西路）”约 350 米、双向四车道，于 **2026-06-04** 开通的消息；[浙江在线 2026-06-03《90早新闻》](https://zjnews.zjol.com.cn/zjnews/90zxw/202606/t20260603_31702006.shtml)引述“看余杭”同一开通日期。2024 年[杭州网工程进展](https://hznews.hangzhou.com.cn/chengshi/content/2024-03/29/content_8708606.htm)称该一期项目 352 米、设计 40 km/h，预计当年 4 月具备通车条件；“计划具备条件”不能当作实际通车日期。

北延的官方账号**稳定原帖链接、绝对发布时间和完整通告尚未取得**；直接打开微博主页得到较旧缓存，没有该通告。搜索结果“12 分钟前”和抓取年龄均未当作发布日期。其证据质量是“官方账号索引 + 地方媒体相互印证的 reported”，并非已留档的完整正式通告。固定 way1228913715 只有两节点直线，不能由双向四车道文字凭空生成精确分车道线形或转向。该段保留 `hold-physical-reconstruction-and-current-primary-notice`。

发现并保留了两次真实临时交通措施，避免把“通车”理解成永久无条件开放：

- [2025-06-06 余杭政府网站／余杭时报](https://www.yuhang.gov.cn/art/2025/6/6/art_1532133_59142985.html)的高考管控报道：6 月 7—10 日指定考试时段，云联路“文二西路—菜鸟北路”禁止机动车，文二西路相关段亦限行。原始 HTML 已留档。这是 2025 年考试期间的临时措施。
- [余杭发布政务号 2026-06-03 公告全文](https://m.thepaper.cn/baijiahao_33300540)，落款为区公安分局交通管理大队：6 月 7—10 日指定考试时段，云联路“菜鸟北路—文一西路”禁止货车、机动车禁鸣；文二西路“智溢路—云联路”禁止所有机动车。该完整正文已通过 web 工具直接读取，直连 HTML 存档失败，留有明确方法的观察 JSON。其对云联路北延作为正常车行道路的语义形成旁证，仍不提供精确几何。

两次公告均限定考试日期和时段，截至本轮日期已经过期，不能直接解释为 2026-10-16 永久 `access=no`。有限检索没有得到该日完整现场标志、施工围挡、车型及转向条件清单，**不能宣称已排除全部后续限制**。站内接口存在强制分词、排序和分页，地址或泛词匹配会产生假相关；[search-audit.json](search-audit.json) 明记检索页数、总命中量、实际道路名匹配及不足。

## 园区内部、其他道路与拓扑边界

以下不由 2023 公告开放：

- 数云路南行 `779247993`、文二西路东行 `477207222` 的 `access=no`：在公告中被用作相交道路，不等于这些整条 way 获准全线开放。
- 西侧施工道路 `1464066099`、附近跨线桥 `1039904654`，以及云联路两条长 way 在凤新路以南的剩余部分：没有本轮公告开放依据。

菜鸟北路西端 `13037359844` 只与云联路北行共享节点；邻近云联路南行的 `7276172384` 是另一节点。**不能按线段二维相交或位置邻近补出转弯路口。** 保留原有北行→文二西路西行短段→云联路南行的源节点回路，CPU 图检查可从凤新路公共路口到菜鸟北路北侧门前节点 `14008463188` 并返回。该节点只是可达性研究点，不是已验收的停靠区、交互入口或园区进入许可。

8 条 OSM 公开历史均已归档。`779247995` 与 `779247992` 的 `access=no` 从 2020 年施工状态延续，2023 年底分别改为三级／二级道路后仍保留，之后的编辑亦未删除。因此存在“施工期限制遗留”的充分核查理由；历史本身不能证明编辑者意图，也不能替代现实通行证据。
