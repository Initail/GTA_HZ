## 地方 X/Y 网格和可辨识形体规格

已实际查看一期完整总平及两个细图、指标表，二期完整总平/细图和区位图；公开转载总平只有1080像素宽。图中X约82300/Y约60600，部分楼标H/h和楼层/屋顶标高；**原坐标系、原点、旋转/投影、完整基准说明未确认**，不能直接当EPSG:4326，也不能默认CGCS2000、北京54或杭州独立坐标系。图面精度的小数位不是实测精度。

一期指标表写最大建筑高度59.95m/楼层指标13；这是转载图面reported，不分配给每栋。总部报告厅的18±4m仅是有限规格中的 estimated：4F×3.5–4.5m公共建筑层高+0–2m屋顶，方法和误差写明，未据此建模。其他真实逐栋高度保持unknown。

形体方案必须保留：高低体量差、圆角外包、横向白挑檐/深玻璃、屋顶绿化和中央设备体、低翼/平台、弯曲公共联系平台及其空隙、东侧附属金色/浅色宽屋顶和玻璃。官方真实全景与转载总平/效果图分开看；**转载鸟瞰图是效果图/方案视图，未当2026现状照片**。这些结构可支持后续可辨识主体，不能先用等高盒块称交付。

图面有人行/车行入口及平台路径，现状WGS84落位、过街净高、地面/平台标高和公开通达性仍unknown。政府[2023道路开通公告](https://www.yuhang.gov.cn/art/2023/5/11/art_1229175530_4164198.html)报告云联路、菜鸟北路已于2023-05-12开通；源OSM部分access=no与现实开通信息是需要主集成核对的差异，**本轮未改导航/access标签**。
