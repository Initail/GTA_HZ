本轮交付的是可重建的独立 B 模块与冻结规格。地标任务 CLI 的有限外观 scope 已实际通过 `evidence-ready`；尚未导出 GLB，未到 `modelled` 或 `verified`。主楼包含环体、四个开放院落、四条对角连接、中央中庭、五层分层鸟喙入口和向入口弯折的玻璃面。邻近产业园塔楼、报告厅与真实室内另列 pending。

## 可重建入口

模块：`scripts/landmarks/cainiao_headquarters.py`，接口 `build(b, lm, spec, scale=.6)`。脚本只向传入 B 添加几何；不 import bpy、不清空场景、不导出资产。`ground_footprints` 只返回候选实体带、连接臂和中庭的地面多边形，保留四院及估计东侧门洞；它不证明实际入口可达。

CPU 检查：

```sh
python3 docs/hangzhou/research/ali/cainiao-round2/check_candidate.py
python3 docs/hangzhou/research/ali/cainiao-round2/render_cpu_preview.py
```

实际通过：来源哈希/完整足印循环、有限坐标、源外轮廓顶点保留、0.60 缩放一次、游戏单位的锚点/基面不再缩放、不同 lm 经纬度锚点的补偿、异常时恢复 B.frame、四处院落无遮挡/无地面碰撞填充、对角臂不穿出圆角轮廓、估计门洞打开、三角形/材质预算。检查范围在 `cpu-validation.json`，不替代完整碰撞、导航或 GPU 检查。

`cpu-preview-*.png` 是标注了用途的 CPU 画家排序图，绑定当前模块/spec SHA256。它可能有排序造成的局部叠面，不能称为 GLB 渲染、实机截图或形体验收通过。

## 来源与视觉范围

原始多方向照片、设计方授权文章和哈希在 `references/`。Aedas 自有页面的园区全景、庭院和入口，与供稿文章的鸟瞰、入口斜面/正面和玻璃细节已逐图检查。邻近产业园高层楼的近景照片未被当作主楼立面。

照片支持：圆角周边环体、四向院落、对角连接、中央屋顶光井、低层玻璃面、内院细竖构件、部分悬臂会议盒，以及入口的多层弧带和玻璃下折。室外玻璃上的小角形印记采用原创稀疏几何近似，不宣称精确品牌笔画或幕墙工程排版。使用共享 `landmarkglass/darkglass/silver/concrete/roof/gold`；颜色和金属响应仍需 GPU 调整。公开夜景虽能看到入口亮带，本模块未增发光或灯，真实夜间控制条件另待核验。

参考照片只作为本地研究证据，没有接入 public、模型纹理或产品 UI。来源照片许可不能由项目 MIT 覆盖；OSM 数据应保留 ODbL 与 OpenStreetMap contributors 署名。
