# 阿里巴巴西溪 C 区：独立外观候选 round2

对象为**西溪五期 / C 区**，不是西南侧六期钉钉总部，也不是 A/B 区。当前交付是源绑定模块、冻结规格、证据任务包及 CPU 结构验证。`evidence-ready` 已实际通过；没有在本子任务内导出 GLB 或进行实机验收，不能视为整个 C 园区完成。

本轮有限范围包含六栋 C1–C6、访客中心、二层 Exchange Ring 的外部连接段、南侧 Media Roof / Ali Roof，制作幕墙分层、银色竖梃、出挑楼层带、六条长中庭天窗、浅屋顶退台框架和入口外观提示。逐栋高度、连桥位置/宽度、屋顶细节均保留估计性质。中央湖、地形基座、室内、园林圆环雨棚、精确字牌和夜景不混入建筑模型。

## 本轮验证

实际执行：

```sh
python3 -B docs/hangzhou/research/ali/alibaba-c-round2/check_candidate.py
python3 -B docs/hangzhou/research/ali/alibaba-c-round2/render_cpu_preview.py
python3 -B scripts/landmark_tasks.py check --job docs/hangzhou/research/ali/alibaba-c-round2/task/alibaba-c/job.json --stage evidence-ready --record
```

CPU 13 组检查通过：8 精确排除对象、外环/内环顶点保留、固定源哈希、有限几何、面数/材质预算、单次缩放与游戏高度、不同地标标记点下的 WGS84 恢复、成功/异常都恢复 builder frame、六中庭碰撞与不透明屋顶空隙、访客凹口及面积守恒、连桥/长檐下方不整块封堵、非全园区碰撞代理、逐栋估计参数、无场景初始化/导出/照片贴图。

候选生成 **16,179 triangles、6 个现有材质、0 新灯、0 照片贴图**。`ground_footprints` 输出 116 个几何碰撞片，包含精確楼体带/访客凹多边形和估计支柱；有限探针不证明所有路线可通行。实际 GLB 面数/体积/GPU 材质、浏览器加载、FPS 均未测试。八项最终验收仍 unknown。
