# 阿里巴巴西溪 B 区：独立有限外观候选 round2

当前 B 区源地块是 OSM way/544285896（阿里巴巴数字生态创新园）。NBBJ 官方四期现状照片的东西蜂巢楼群，与该地块内固定足印吻合；[Benoy 项目页](https://www.benoy.com/projects/alibaba-xixi-park-iv)也陈述东西两组、中心体育设施与西南访客中心。现代 B 区的全部历史期次、楼栋编号和中央两片 roof 的功能对应尚未核实，保留 blocker，不混用 A/C 形体或历史概念总图。

本轮仅交付 19 个连通楼臂/节点/访客中心 source Ways 和 2 个可对应绿屋顶的外观候选。**23 个 OSM building/roof 要素不是 23 栋独立主楼**；可确认的组织为两个连通蜂巢组加西南访客中心。具名实体楼栋数量与 B1/B2 等编号 crosswalk 仍 unknown。

任务已实际通过 `evidence-ready`，模块及 CPU 检查已完成。未在本子任务中启动 Blender、导出 GLB、浏览器或进行实机验收，不能据此宣布 B 园区完成。

## 形体与估计

[NBBJ 四期官方资料](https://www.nbbj.cn/work/alibaba-xix-campus/)包含已完成航拍、屋顶俯视和多方向街面照片。源折线网格、低顶庭院、局部架空、竖向暖橙遮阳与银色水平幕墙可辨识；本轮按各 source Way 保留几何转折，未用统一盒块代替整个园区。相邻楼臂共享边界分段后按邻楼高度隐藏内部共面幕墙，避免接缝重复。

候选最高办公臂为 **34±8m estimated**，较低办公臂 **25.4±7m estimated**，节点 **14.4±5m / 19.6±6m estimated**，访客 **18.5±5m estimated**，两低绿顶 **5.8±2.5m estimated**。方法为现状照片人物尺度/约6m公共与架空层 + 4–6 个可见幕墙课程、约4.2–4.7m课程间距，并用 mapped20–40m楼臂宽度检查比例。透视、局部遮挡和课程/实际楼层关系均有误差；这些数值不是逐栋竣工 measured/reported 数据。

Benoy 当前室内案例页面列 `Height:134 feet`（换算40.8432m）、55,000m²、2025；其度量对象和标高基准不明，作为 reported 原文记录但不作为全部楼臂真实高度。NBBJ 的180,000m²是项目面积，不是源平面面积。没有将 C 区80m参数用于 B 区。

屋顶六角绿块半径11±3m、约0.55m高差和5±2m三角天窗按官方屋顶/街面照片比例估计，仅生成完整落在源轮廓内的 cells。本候选有11个植被屋顶单元，其数量/配准不等于完整实际屋顶花园。地面玻璃退入2.4m、柱距14m、遮阳几何采样1.8m、屋顶设备位置与入口外观均为程序化候选；精确设备/植物/门洞库存未冻结。
